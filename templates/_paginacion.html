{# Paginación reutilizable. Dos cosas que las versiones anteriores hacían mal: 1. Decidían si había página siguiente con `items|length == por_pagina`. Si la última página traía justo el tamaño del bloque, aparecía "Siguiente" hacia una página vacía. Aquí se usa el total real. 2. Los enlaces eran `?pagina=N` a secas, así que al cambiar de página se perdían los filtros. `request.args` conserva todo lo demás. Uso: {% from '_paginacion.html' import paginacion %} {{ paginacion(pagina, por_pagina, total) }} #} {% macro paginacion(pagina, por_pagina, total) %} {% set paginas = (total // por_pagina) + (1 if total % por_pagina else 0) %} {% if paginas > 1 %}
{% if pagina > 1 %} ← Anterior {% else %} ← Anterior {% endif %} Página {{ pagina }} de {{ paginas }} ({{ total }} en total) {% if pagina < paginas %} Siguiente → {% else %} Siguiente → {% endif %}
{% endif %} {% endmacro %}
